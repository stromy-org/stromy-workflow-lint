# Stromy workflow lint

Public composite action for offline GitHub workflow and action lint. The source
is generated byte for byte from a reviewed commit of Stromy's private control
plane. It runs pinned actionlint 1.7.12, zizmor 1.30.1, and shellcheck 0.11.0.

Consumers pin this action to a **full commit SHA** and own their own exact
finding baseline:

```yaml
- uses: stromy-org/stromy-workflow-lint@<full-commit-sha>
  with:
    root: .
    baseline: .github/workflow-lint/baseline.json
```

The action returns 0 when findings match valid holds, 1 when findings changed,
and 3 when collection or a required input was unavailable. The baseline is
never supplied or changed by this repository. The action takes no token input.

`lint/workflow-lint-bundle.json` records the canonical source commit and SHA-256
of each copied file. The generating source and release process are governed by
ORG-PLAN-390/C5 in `stromy-org/stromy-org`.
